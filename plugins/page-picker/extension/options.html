pi-web-ui service
Localhost and 127.0.0.1 are pre-authorized. For a LAN, remote, or HTTPS URL, authorize the exact address first. The easiest option is to click the extension icon on the open pi-web-ui page. Delivery targets that open browser tab, so keep it open; otherwise the extension copies Markdown as a fallback.

AI page control
After authorization, the model can use the browser_page tool through the open pi-web-ui tab. It can read, click, type, scroll, navigate, wait, and optionally run JavaScript or capture a screenshot. Only authorize pages you trust; permissions can be revoked at any time.
Click the extension icon once on a target page to add it to the candidate list, or use the picker bar's "Let AI control this page..." action.
Page bridge
Pair two trusted pages to let their scripts call one another. A receiving page can register window.__piBridge.on("readOrders", () => ...); the caller can use await window.__piBridge.call({ op: "readOrders" }). The bridge is off by default and only listed pairs are allowed.
Click the extension icon once on each page to add both addresses to the candidate list. The bridge refuses closed pages, unknown actions, and oversized results instead of failing silently.
